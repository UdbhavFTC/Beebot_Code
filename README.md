# Beebot_Code
Project Synopsis

BeeBot is an AI-powered autonomous pollination system designed to assist pollination in environments where natural pollinators are limited. The system combines computer vision, robotics, and autonomous navigation to identify flowers and potentially perform targeted pollination.

The project's core computer-vision component uses a custom flower-recognition dataset and YOLOv8 to detect and classify flowers. This information is intended to guide an autonomous robotic platform toward suitable flowers, with future integration of technologies such as LiDAR-based navigation and a mechanical pollination mechanism.

BeeBot was developed with a focus on addressing challenges surrounding pollination and agricultural sustainability, aligning with UN Sustainable Development Goals 2 (Zero Hunger) and 13 (Climate Action). The project also explores how AI-driven robotics could complement natural pollination systems rather than simply replacing them.

The project includes the development of the AI pipeline, dataset preparation, software documentation, CAD designs, and research into existing flower-recognition approaches. A literature review examining 600+ papers on flower recognition was also conducted to understand the current state of computer vision in this domain.

Key technologies: Python · YOLOv8 · Computer Vision · AI/ML · Robotics · CAD · Autonomous Navigation
